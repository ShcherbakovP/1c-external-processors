# MVP IKassaПробник.epf — спецификация

**Цель:** проверить на целевой рознице, что 1С может говорить с PAX A930 по локальному API Smart X, и понять, какие из задокументированных операций реально работают. Только **read-only / нефискальные** операции.

## Форма (одна, управляемая)

### Реквизиты формы
- `Адрес` (Строка, default `192.168.0.x`)
- `Порт` (Число, default `37015`)
- `PIN` (Строка, пароль) — не сохраняется в настройках, вводится каждый сеанс
- `Кассир` (Строка, default `"Тест"`)
- `AuthToken` (Строка, заполняется после AUTH)
- `ТокенДо` (Дата, заполняется после AUTH)
- `Лог` (ТекстовыйДокумент или ФорматированныйДокумент) — реверс-режим логирования: новые записи сверху

### Команды на форме
| Кнопка | Тип операции | Что показываем |
|---|---|---|
| `🔐 AUTH` | `AUTH` | Сырой запрос, сырой ответ, сохранённый токен, срок действия |
| `📊 X-отчёт` | `X_REPORT` | Сырой ответ + распарсенные ключевые поля (выручка, кол-во чеков) |
| `📋 Документы смены` | `GET_SHIFT_DOCUMENTS` | Таблица: время, тип, сумма, фискальный номер |
| `🧾 Тест печати` | `PRINT_BASE64` | Отправляем простой нефискальный текст «MVP TEST» — проверяем, что принтер реагирует |
| `📦 Выгрузить логи` | `UPLOAD_LOGS` | Сохраняем ответ в файл |
| `🔍 SSDP discovery` | (UDP мультикаст) | Список найденных касс с IP/серийником |

### Поле «Лог» — формат
```
[14:32:01] → POST http://192.168.0.100:37015/v1   header INTENT_OPERATION_TYPE=AUTH
            BODY: {"pin":"***","rememberPin":true,"returnToken":true}
[14:32:02] ← 200 OK (845 мс)
            BODY: {"messageDetail":"Авторизация выполнена","resultCode":200,"token":"...","type":"AUTH"}
```

## Что НЕ делаем

- Никаких `SALE`, `OPEN_SHIFT`, `CLOSE_SHIFT`, `ROLLBACK`, `DEPOSIT`, `WITHDRAW`, `CHEQUE_PAYMENT` — это фискальные операции
- Никаких изменений в типовой конфигурации 1С:Розница
- Никакого сохранения PIN в файлах (только в памяти текущего сеанса)
- Никакого облака АИС ПКС

## Контракт проверки связи

После запуска MVP на месте проверяем последовательно:

1. **Пинг сети**: с ПК кассира `Test-NetConnection -ComputerName <IP> -Port 37015` → должно быть `TcpTestSucceeded: True`. Если нет — режим сервера на A930 не включён, или сеть не пускает.
2. **AUTH**: получили `resultCode: 200` и `token`? — да/нет, время отклика.
3. **AUTH повторный по токену**: положили `Auth-token` в header, отправили `X_REPORT` без PIN — работает?
4. **X-отчёт**: какие реквизиты возвращает, есть ли НДС, есть ли разбивка по секциям.
5. **GET_SHIFT_DOCUMENTS**: формат `SALE` в журнале — совпадает ли с описанным в `smartx_manual.txt`.
6. **Тест печати**: реагирует ли принтер на `PRINT_BASE64`.
7. **Логи**: формат и размер `UPLOAD_LOGS`.
